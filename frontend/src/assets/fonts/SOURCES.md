# Fontes locais

Os ficheiros WOFF2 são subconjuntos latinos servidos localmente, para não
carregar fontes de terceiros no navegador.

| Ficheiro | Família | Origem | Versão/licença |
| --- | --- | --- | --- |
| `ibm-plex-sans-latin.woff2` | IBM Plex Sans | [IBM Plex](https://github.com/IBM/plex) / [Google Fonts](https://fonts.google.com/specimen/IBM+Plex+Sans) | pacote distribuído em 2026-09-08; SIL OFL 1.1 |
| `playfair-display-latin.woff2` | Playfair Display | [Playfair Display](https://github.com/clauseGG/Playfair-Display) / [Google Fonts](https://fonts.google.com/specimen/Playfair+Display) | pacote distribuído em 2026-09-08; SIL OFL 1.1 |

Os avisos completos das licenças acompanham cada família. Antes do lançamento,
confirmar a versão embutida nos metadados dos WOFF2 contra os repositórios de
origem.
