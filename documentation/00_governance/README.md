# Governance

Esta secao governa como a documentacao e escrita e evolui.

## Responsabilidade
- Alinhar estrategia, dominio e implementacao sem contradicoes.
- Garantir que informacao nao confirmada nao entra como verdade.
- Preservar separacao por layers de clean architecture.

## Regras fixas
- Nao substituir hard constraints por conveniencia visual ou operacional.
- Nao violar isolamento por organization_id em qualquer definicao funcional.
- Nao misturar comportamento de interface com regra de negocio sem explicitar fronteira.

## Donos de decisao (nivel produto)
- admin representa autoridade de aprovacao dentro da organizacao cliente.
- professor possui escopo restrito a disponibilidade e consulta do proprio horario.
