# Glossary

## Purpose

This document defines technical abbreviations, controlled vocabulary, and domain-specific Portuguese terms used in Cronos documentation.

## Intended Reader

This document targets all engineers and technical writers.

## Controlled Vocabulary Standard

In accordance with ASD-STE100, technical concepts have single approved terms. Portuguese domain terms remain in their native form to match educational legislation and user interface labels.

## Domain Terms (Portuguese)

| Term | English Translation | Definition |
| :--- | :--- | :--- |
| **Ensino Profissional** | Professional Education | Vocational secondary education in Portugal, structured around modular course plans. |
| **Equipa** | Team | The organization membership view where administrators manage staff members and invites. |
| **Turma** | Class / Student Group | A cohort of students enrolled in a specific year and course. |
| **Módulo** | Module | A self-contained instructional unit with a defined instructional time requirement. |
| **Módulo selecionado** | Selected module | A module marked for a class/subject link in the current school year. Only selected modules are planned and counted in progress. |
| **Módulo retirado** | Retired module | A module deselected on a class/subject link. With executed history it stays closed at the executed minutes and receives no new credit. |
| **Junção** | Joint lesson group | A subject, two or more member class/subject links, and a set of joint modules. A link belongs to at most one group. In the interface: "Aula conjunta". |
| **Aula conjunta** | Joint lesson | A lesson of a joint group, taught to every member class at the same time, by one teacher, in one room. Each member class has one sibling lesson row. |
| **Módulo conjunto** | Joint module | A module of a joint lesson group. It must be selected on every member class and is taught to all of them together. |
| **Sumário** | Lesson Log | Formal record of lesson execution, topics taught, and student attendance entered by a teacher. |
| **Falta** | Absence | Record of teacher absence for a scheduled lesson block. |
| **Substituição** | Cover / Substitution | Arrangement assigning a replacement teacher or subject to an absence block. |
| **Bloco** | Schedule Block | A dated timeslot assigned to a class, subject, teacher, and room. |
| **Horário** | Schedule / Timetable | The weekly distribution of schedule blocks across classes and teachers. |
| **Fundação (Foundation)** | Foundation | Required ten-step organization setup that validates the calendar and generates the initial timeslot grid. |
| **Professor competente** | Competent teacher | Active teacher assigned to a subject with the required competency. |
| **Disponibilidade** | Availability | Teacher availability score used to determine whether a generated assignment is possible. |
| **Disponibilidade da turma** | Class availability | Weekly level per class block (Preferencial, Neutro, Evitar, Impossível) that excludes or penalizes periods in generation; a missing row means Neutro. |
| **Nível de disponibilidade** | Availability level | One of the four levels per weekly block: Preferencial, Neutro, Evitar, Impossível. A missing row means Neutro. |

## Technical Terms and Abbreviations

| Abbreviation / Term | Full Name | Definition |
| :--- | :--- | :--- |
| **API** | Application Programming Interface | RESTful HTTP interface provided by the backend service. |
| **Beat** | Celery beat scheduler | Process that publishes periodic Celery tasks. |
| **CP-SAT** | Constraint Programming - Satisfiability | Optimization solver engine from Google OR-Tools used for schedule generation. |
| **JWT** | JSON Web Token | Signed authentication token generated by Clerk and verified by the backend. |
| **Nginx** | Web server | Serves the compiled frontend and proxies `/api/` requests to the backend. |
| **Occurrence** | Operational occurrence | Record that explains a scheduled block outcome, such as a gap or substitution. |
| **RBAC** | Role-Based Access Control | Capability checks based on active membership flags (`admin`, `teacher`). |
| **Recovery link** | Recovery relation | Link from an adaptive repair block to the original published block. |
| **RLS** | Row-Level Security | PostgreSQL feature that enforces tenant isolation per row. |
| **STE** | Simplified Technical English | Controlled writing standard (ASD-STE100) used for documentation clarity. |
| **Foundation status** | Organization setup state | `NOT_STARTED`, `IN_PROGRESS`, or `COMPLETED`; it controls the normal authenticated route gate. |
| **Readiness depth** | Operational readiness level | Cumulative level from 0 to 6 that measures whether the bases for schedule generation exist. |
| **Prevalidation** | Generation preflight | Pure check that returns blockers, warnings, and a fingerprint before a generation request. |
| **Draft version** | Optimistic concurrency version | Monotonic version sent as `expected_version` to prevent overwriting another administrator's draft. |
| **Current member** | Local organization member | The tenant-scoped membership returned by `/members/me` and used by route guards. |
| **Tutorial run** | Local tutorial execution | Browser-scoped tutorial state identified by a run ID and separated from operational data. |
| **Tutorial checkpoint** | Local tutorial progress | Minimal browser-only state with a 30-day expiry; it is not an operational record. |
| **Preparation dashboard** | Pre-operational dashboard | Dashboard mode shown after Foundation and before the first real schedule approval. |
| **Operational dashboard** | Active operations dashboard | Dashboard mode shown after the first real schedule approval. |
